A380X aileron and hydraulic surface visual animations

The included plugins/A380XAileronDatarefs plugin registers the 22 animation
datarefs before X-Plane loads the objects and drives them itself from a flight
loop: a native C port of the FlyWithLua drivers and modules listed below. No
FlyWithLua installation is needed. While the native driver runs it publishes
a380x/xp12/hydraulics/native_driver = 1; the FlyWithLua drivers then stand down,
so there is never a second writer. Keep the plugin folder in this aircraft.

Only custom visual values are written; flight physics and the simulator's
flight controls are never changed. The six legacy and eight hydraulic ratios
use [-1, 1]; the eight hydraulic spoiler angles use [0, 65] degrees.

The packaged FlyWithLua files (plugins/FlyWithLua/) are the reference the native
driver is tested against, frame by frame. They are only needed for an aircraft
folder named A380X-XP12 whose plugin predates the native driver: install
FlyWithLua NG (tested API 2.8.12), then, with X-Plane closed, copy
plugins/FlyWithLua/Modules/*.lua to X-Plane 12/Resources/plugins/FlyWithLua/Modules/
and plugins/FlyWithLua/Scripts (required)/*.lua to .../FlyWithLua/Scripts/.
Back up existing files first. Do not enable the optional FBW control-law script.
Offline tested (mock XPLM, Lua 5.4 golden comparison), not a simulator flight test.
